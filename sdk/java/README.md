# Better Stack Pulumi provider

A Pulumi package for managing errors, incidents and telemetry resources in Better Stack.

Maven Central `com.betterstack:pulumi`, package `com.betterstack.pulumi`:

```xml
<dependency>
    <groupId>com.betterstack</groupId>
    <artifactId>pulumi</artifactId>
</dependency>
```

Docs, with an example in every language: [Pulumi Registry](https://www.pulumi.com/registry/packages/betterstack/). Report bugs and
requests in [`BetterStackHQ/pulumi-betterstack`](https://github.com/BetterStackHQ/pulumi-betterstack/issues).

The provider bridges the Better Stack Terraform provider
([`BetterStackHQ/terraform-provider-betterstack`](https://github.com/BetterStackHQ/terraform-provider-betterstack)) and, like it,
is licensed under Apache-2.0.
